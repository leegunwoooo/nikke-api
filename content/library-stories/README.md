# 영상에서 옮긴 `library` 스토리

CDN에도 커뮤니티 기록에도 아직 없는 스토리의 대본입니다. 빌드할 때 `library` 카테고리에 합쳐져 API와 MCP로 제공됩니다. CDN이나 기록에 같은 이야기가 올라오면 빌드에서 자동으로 빠집니다. 파일의 대사가 절반 이상 겹치면 파일 전체가, 장면의 대사가 90% 이상 겹치면 그 장면이 빠집니다.

| 파일 | 내용 | 영상 |
|---|---|---|
| `maria-n-1.json` | MARIA-n 1부, 14장면 1,898줄 | <https://youtu.be/dFUHTzKGUrM> |
| `maria-n-2.json` | MARIA-n 2부, 13장면 2,458줄 | <https://youtu.be/EcvO4LOgOqs> |
| `maria-n-epilogue.json` | MARIA-n 에필로그 컷신 `검은 달 안에서`, 34줄 | <https://youtu.be/Dg6Xm9isBIU> |

## 출처와 저작권

공개 유튜브 영상의 화면을 OCR로 읽어 옮겼습니다. 대본의 저작권은 **© SHIFT UP / Level Infinite**에 있습니다. 비상업적 팬 프로젝트의 자료이며, 권리자가 요청하면 즉시 삭제합니다.

## 형식

```json
{
  "collection": "묶음 이름 (감상 순서의 제목과 같아야 연결됨)",
  "libraryCategory": "event_stories",
  "sourceVideo": "원본 영상 주소",
  "scenes": [{ "groupId": "lib_*", "name": "장면 이름", "lines": [] }]
}
```

`lines[]`는 `/api/scenes/:groupId` 응답과 같습니다. `window`는 `Speech`, `Self`(지휘관 대사), `Narration`이고, 화자 코드와 음성은 없습니다.

## 정확도

- 다른 영상의 OCR 결과, 자동 자막과 비교하고 전 줄을 프레임과 대조했지만 오탈자가 남아 있을 수 있습니다.
- 영상에 들어 있던 업로더 닉네임은 `@UserName`으로 바꿨습니다.
- `…….`처럼 글자로 잘 읽히지 않는 침묵 대사는 화자 이름이 표시되는 구간을 기준으로 대조해 넣었습니다.
- 지휘관의 대사는 게임에서 버튼 하나짜리 선택지로 나오지만, 고를 수 있는 다른 항목이 없어 일반 대사(`Self`)로 넣었습니다.
- 2부는 [다른 영상](https://youtu.be/EMAtDrrz2zA)의 OCR과 줄 단위로 비교했고, 장면 이름은 그 영상의 앨범 화면에서 가져왔습니다.
- OCR이 읽지 못하는 짧은 줄(`…….`, `!!`, `응.`)은 지휘관 버튼의 `[1]` 표시와 줄 끝의 `▼` 표시를 전체 프레임에서 이미지로 찾아 대본과 맞췄습니다.
- 2부 가위바위보 장면(`lib_maria_n_2_04`)의 버튼 3개는 모두 `보를 낸다.`여서 한 줄로 넣었습니다.
- 2부 `lib_maria_n_2_01`의 선택지는 항목이 둘(`Choice`)입니다. 대본의 영상은 [1]을, 비교한 영상은 [2]를 골랐고, 이어지는 대사는 같습니다.
- 에필로그는 컷신만 옮겼고 필드를 돌아다니며 나오는 대화는 없습니다. [다른 영상](https://youtu.be/vewPzMKmTvk)(앨범 재생)의 OCR과 비교했고, 두 영상의 `▼` 표시 수(34)가 대본 줄 수와 같습니다. 장면 이름은 그 영상의 앨범 화면에서 가져왔습니다.
- 끝에 문장부호가 없는 줄은 다음 줄로 문장이 이어지는 경우로, 화면에 표시된 그대로입니다.
